# 美术交付

统一方向：山间微缩药铺、暖木桌、鼠尾草绿、纸包米色、竹篮与土壤，植物辨识特征优先于装饰。

已读取 imagegen SKILL.md，但当前工具列表中无 image_gen，未调用任何图像生成 API。按用户明确允许的后备路线，全部运行资源由源码生成，不需要外部模型或远程图片。

| 资源 | 制作方式 | 源文件 |
|---|---|---|
| 银露叶、青铃叶、暖心根、星绒花 | 自定义有叶脉的弯曲网格、对生/互生/轮生、绒环/方茎/根肩几何体 | src/art.js, src/scene.js |
| 根片、受损叶、鲜料和干料 | 按批次操作位置与完整度生成 | src/scene.js |
| 木纹、泥土、纸张、叶脉 | 带固定随机种子的 CanvasTexture | src/art.js |
| 竹篮、竹筛、罐子、桌子、小铺、林木与溪流 | 程序化 3D 几何体，静态环境按材质合并 | src/scene.js |
| 图标和 favicon | 原创 SVG | src/art.js, public/favicon.svg |
| 开始界面 | 实际 Three.js 药铺场景 + 原生文字 | src/main.js, src/style.css |
| 环境声与结算反馈 | Web Audio 合成溪水噪声与三音提示 | src/audio.js |

未添加敌人和武器，因本项目明确暂缓战斗；工具、植物与经营图标已覆盖实际玩法。

后续可供 imagegen 使用的方向提示词（当前未执行）：精致可爱的写实微缩山间草木药铺，暖木桌、竹篮、纸包和陶罐，柔和自然散光，鼠尾草绿与米色。植物辨识样本为虚构银露叶（宽卵形对生叶、圆茎白绒环）、青铃叶（锯齿狭长互生叶、方茎）、暖心根（心形放射叶、橙色根肩横纹）、星绒花（线形轮生叶、五瓣星花），形状差异清楚，无治疗暗示、无文字、无武器。
