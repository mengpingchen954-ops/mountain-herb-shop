# 山间药铺 · Mountain Herb Shop

原创温馨浏览器 3D 游戏。辨识虚构植物，选择地点、成熟度与采集部位；刷泥、切片、挑选去杂、摊晾并加工；按等级与规格完成顾客订单。

所有植物均为虚构，不提供真实药材识别或治疗建议。

## 运行

需要 Node.js 22.12+ 或 24。双击 `start-game.cmd`，或：

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:5191/ 。不要直接双击 index.html。

```sh
npm test
npm run test:browser
npm run build
npm run preview
```

浏览器测试需要本机 Chrome；另一个终端先启动 dev 或 preview。生产预览使用 4191 端口；测试时设置 GAME_URL。

## 首次试玩

1. 推开铺门 → 进山采集 → 溪畔。
2. 观察植物，点击叶形、叶序、茎/花根三项；对照图鉴。
3. 银露叶是宽卵形对生叶、圆茎带白色绒环。青铃叶是锯齿狭叶、互生叶、方茎。错误判断可纠正。
4. 选择叶部，保留基部后采集。返回推进一段。
5. 工作台选择批次并确认开始。点击两片褐色残片与灰色碎石，保留好叶。
6. 六只竹筛都摊开，选择通风阴干。查看等级原因。
7. 订单里选择符合要求的批次，预览并交付。

根类工序使用鼠标或手指刷过可见泥点；四刀位置影响五片厚薄，也可使用精确位置按钮。暂停、离开、刷新后可继续本批。

## 已实现

- 四种虚构植物，两处采集地点；三项可见特征、旋转与缩放观察。
- 图鉴记录特征、辨识纠正、成熟期、采集部位与实际加工结果。
- 八段时节循环，晴朗/多云/小雨；行动推进时间。
- 三份一批的来源与成熟度记录；采后再生，保留基部或主根影响周期。
- 独立未确认样本及原株确认，错部位不能加工或冒充订单。
- 两条加工路线：根类刷泥/切片；叶花类挑选去杂；共同摊放与设备选择。
- A/B/C 品质与逐项原因，干燥和储存实时影响等级。
- 鲜料阴凉篮、干料纸包/密封罐/敞口筛，雨天吸潮和回干。
- 三类顾客、六份规格订单，基础出售，完整收支，恒温干燥柜解锁。
- 原批次保存加工结果，防重复采集、扣料与结算；localStorage 自动存档、上一份有效备份、导入导出。
- 程序化 3D 植物、木纹/土壤/叶脉/纸张 Canvas 贴图，SVG 图标、柔和阴影与合成溪水音。
- 自适应手机界面、降低画质选项、减少动态效果偏好、WebGL 上下文恢复。

## 架构与规则

`src/rules.js` 是纯数据规则；`scene.js` 是 Three.js 画面和命中区域；`main.js` 是 DOM 交互；`storage.js` 管理校验与备份。诊断接口 `window.herbShop` 只提供状态复制、画面目标坐标和性能信息，测试不直接修改游戏状态。

每两段更换时节：早春 → 暮春 → 初夏 → 晚夏。观察不推进时间；返回出行推进一段；阴干两段、晒干一段、恒温柜一段；全部库存使用同一日历。

品质由成熟度、清洁度、完整度、根片均匀度、含水与保存状态构成。干料水分超过 25% 不可交付订单，超过 35% 不可基础出售；可回干，但回干不恢复早采、杂质或破损。

## 发布

Vite 相对资源路径支持 GitHub Pages 仓库子路径。`.github/workflows/pages.yml` 使用 npm ci、规则测试、生产构建及官方 Pages Actions。发布脚本复用当前 Git Credential Manager 认证，只上传本游戏的明确文件清单；不会把凭据、测试截图、个人文件或本地存档提交到仓库。

## 美术与范围说明

本环境没有可调用的 imagegen 工具。未声称生成 AI 图片；采用原创程序化几何体与 Canvas/SVG 美术，见 `docs/ART.md`。首版为固定视角微缩场景，没有开放世界、战斗、种田或复杂人物动画。Chrome Windows 实际验证；移动端为浏览器视口与输入测试，尚未真机验证 iOS Safari。
